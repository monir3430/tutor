## 🔧 ব্যবহার নির্দেশনা

### কন্টেন্ট আপডেট
1. **ব্যক্তিগত তথ্য:** `index.html` ফাইলে নাম, ঠিকানা, ফোন নম্বর আপডেট করুন
2. **ছবি পরিবর্তন:** `assets/images/me.JPG` ফাইল রিপ্লেস করুন
3. **সেবা ও মূল্য:** প্রয়োজন অনুযায়ী সেবা এবং মূল্য তালিকা আপডেট করুন

### ইমেইল কনফিগারেশন
EmailJS সেটআপ করতে `script.js` ফাইলে:
- Service ID এবং Template ID আপডেট করুন
- Public Key কনফিগার করুন
